2025#电力电子 #课题组

为什么把 cell 换成四电平

在课题组跟的是电力电子变压器（SST）的前级。SST 用中高频的电力电子变换加中频隔离，替掉笨重的工频变压器，把 10kV 中压交流变成低压直流。

前级走的是级联多电平。级联的单元叫 cell，它是可以换的：只要有独立浮地的直流、能全桥双向输出，H 桥、三电平、四电平都能当 cell。要凑出 17 电平，三种 cell 的账是这样的：

cell每个 cell 的电平凑 17 电平问题
H 桥38 个 cell，8 套浮地驱动器件和绝缘做不下来
T-NPC 三电平54 个 cell1200V + 600V，上下管电压和损耗不均
准 NPC 四电平73 个 cell，3 套浮地驱动中间管要扛满 3300V

容易想错的一点：换成四电平，开关总数并没有变少，32 个反而变成 36 个。真正省下来的是浮地驱动。每一套都要隔离供电、隔离采样、中压绝缘，从 8 套压到 3 套，这才是成本和体积的大头。

我做的部分

准 NPC 四电平单元的 Simulink 模型：交流 2.2kV，直流母线 3.3kV（3×1100V）。控制分三层，直流电压外环 PI，电流内环准 PR，最后是 5kHz 的层叠载波 PWM，控制频率 20kHz。

% 准 PR 控制器
G(s) = Kp + Kr · 2·Wc·s / (s² + 2·Wc·s + Wo²)
Wo = 2π·50 ≈ 314 rad/s   % 50Hz 处高增益 → 无静差
Wc = 5 rad/s             % 展宽谐振，抗电网频偏
% Tustin 离散化 → 二阶 IIR，可以直接上 DSP

拓扑方向是课题组定的。目前只验证了单个 cell，多 cell 级联和均压还没做。
