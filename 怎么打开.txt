Colorai 个人站 · 本地版怎么打开
================================

线上地址：https://coloraiyu.pages.dev/
（留言板、问 AI、访客记录、管理面板只有线上版能用；本地版能看所有页面、照片和听歌。）


■ Windows
  双击「启动本地网站.bat」。会弹出一个黑色窗口并自动打开浏览器，关掉黑色窗口就停止。
  如果公司 / 学校电脑禁用了 PowerShell，它会自动改用 Python 或 Node（装了其中一个就行）。

■ Mac
  双击「启动本地网站-Mac.command」。
  第一次如果提示「无法打开」：右键这个文件 →「打开」→ 再点「打开」，之后就能直接双击。
  如果提示没有权限：打开「终端」，输入  bash  加一个空格，把这个文件拖进终端窗口，回车。
  Mac 自带 Python 3（没有的话第一次会提示安装开发者工具，点安装即可）。

■ Linux
  在这个文件夹里打开终端，运行：  sh 启动本地网站-Linux.sh

■ 手机 / 平板
  · 最简单：打开线上地址（或者点「打开线上版」快捷方式）。
  · 想看本地这份：电脑上双击「启动本地网站-手机可访问.bat」（Mac / Linux 在命令后面加 --lan），
    窗口里会显示一个 http://192.168.x.x:8765 的地址，手机连同一个 Wi-Fi 后在浏览器里打开它。

■ 什么都没装、脚本都打不开
  直接双击 index.html 用浏览器打开也行，只是换页时音乐会断一下再接着放。

■ 其他脚本（一般用不到）
  tools/serve.py    Python 版服务器，任何系统：python3 tools/serve.py   （加 --lan 给手机用）
  tools/serve.mjs   Node 版服务器，任何系统：  node tools/serve.mjs     （加 --lan 给手机用）
  tools/serve.ps1   Windows PowerShell 版，「启动本地网站.bat」用的就是它
  tools/publish.ps1 发布到线上（需要先登录 Cloudflare，见 修改指南.md）

改内容的方法见「修改指南.md」。
